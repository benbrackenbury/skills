# Encode Lessons in Structure

A lesson that only lives in a skill, a comment, or your head will be forgotten. Put it where the next run cannot skip it.

- Prefer a type, assertion, lint, or small script over a paragraph of instructions
- If you already wrote "don't do X" twice, the third time is a check that fails when someone does X
- Docs last. They explain the check. They are not the check
